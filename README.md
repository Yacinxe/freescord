# Projet-Freescord
J'ai réalisé ce projet dans le cadre d'un cours de systèmes/réseaux. Il s'agit d'une application Client-Serveur réalisée en C. Le but est de gérer les connexions simultanées par threads, la synchronisation par mutex/sémaphores et une interface GTK3. Il permet de transférer des données et gérer les clients dynamiquement par liste chaînée.
